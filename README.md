# 달빛 타로

질문을 입력하고 실제 타로 스프레드 형태로 카드를 뽑아 해석할 수 있는 웹사이트입니다.

- 1장, 3장, 5장, 선택지, 켈틱 크로스 스프레드
- 카드 수동 공개 또는 전체 자동 공개
- 정방향·역방향 지원
- 퍼블릭 도메인 Rider–Waite–Smith 카드 이미지 사용
- 반응형 모바일 UI

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 확인할 수 있습니다.
